# realvibes

Веб-приложение (React 18 + TypeScript + Vite), реализующее:

- построение блок-схем алгоритмов в соответствии с ГОСТ 19.701-90 (процесс, решение, ввод/вывод, документ, данные, предопределённый процесс, соединитель, комментарий, терминатор);
- экспорт схемы в PNG (2×), SVG и в буфер обмена (как PNG);
- редактор листингов кода с превью «как в Word» (таблица «№ | Код»);
- генерацию `.docx` с таблицей листинга и (опционально) вставленной схемой.

## Быстрый старт


## Возможные ошибки и их решение

1. **Ошибка `Cannot find module '@xyflow/react/dist/style.css'`** — установите зависимости (`npm install`). Файл стилей подключается в `src/main.tsx` и должен идти **до** `./index.css`.
2. **Стрелки/миникарта выглядят «сломанными»** — забыт импорт `@xyflow/react/dist/style.css` (см. п.1).
3. **`ClipboardItem is not defined` при копировании** — функция доступна только в secure-context (HTTPS или `localhost`). В остальных случаях используйте «Экспорт PNG».
4. **`html-to-image` возвращает пустую картинку** — убедитесь, что схема отрисована и `nodes.length > 0`. Функция `exportToPng` ждёт один layout-тик (не вызывайте сразу после `addNode`).
5. **`Packer.toBlob is not a function`** — установлена несовместимая версия `docx`. Нужна `^8.5.0`.
6. **Кириллица в PDF/PNG «квадратиками»** — `html-to-image` использует шрифты страницы; если у вас системный шрифт без кириллицы, установите `font-family` явно (в проекте используется системный стек браузера).
7. **Ошибка TypeScript `Type 'X' is not assignable...` в ImageRun** — в `docx@8+` обязателен параметр `type: 'png'`. Он передан в `exportDocx.ts`.
8. **Word ругается на повреждённый файл** — не редактируйте `.docx` вручную; `Packer.toBlob` формирует корректный docx только при использовании `Table`, `TableRow`, `TableCell` и `borders`. Код `exportDocx.ts` полностью совместим с Word 2016+.
9. **`zustand persist` теряет состояние при перезагрузке** — проверьте, что в браузере разрешён `localStorage` (не приватный режим).

## Как пользоваться

1. **Создать блок-схему** (`Блок-схема`): перетащите нужные символы из палитры на холст. Соединяйте блоки, потянув за маркер. Текст и тип блока редактируются в правом инспекторе. Кнопка «Загрузить пример» подставит демонстрационный алгоритм.
2. **Экспорт схемы**: нажмите «Экспорт PNG (2×)» — файл скачается, а PNG также запомнится в состоянии для дальнейшей вставки в комбинированный `.docx`. «Экспорт SVG» и «Копировать в буфер» — альтернативы.
3. **Создать листинг** (`Листинг`): вставьте код в левый редактор, задайте параметры (шрифт, размер, число строк на странице, подпись, ширину колонки номера). Справа — предпросмотр «как в Word».
4. **Скачать `.docx`**: «Скачать .docx (листинг)» — только листинг. «Скачать .docx (схема + листинг)» — сначала экспортируйте PNG на экране схемы, затем нажмите эту кнопку. В итоге получите документ, где сначала идёт схема (Рисунок 1), затем таблица листинга с подписью «Листинг N — …».
5. **О приложении** (`О приложении`) — сводная таблица ГОСТ 19.701-90 и памятка по ГОСТ 2.105-95.

## Тестовые данные

**Схема «Сортировка пузырьком»** — нажмите «Загрузить пример» на экране «Блок-схема». Или создайте вручную: Начало → Ввод массива A и n → i = 1 → i < n? → j = 1 → j ≤ n−i? → A[j] > A[j+1]? → swap → j++ → i++ → Вывод A → Конец.

**Листинг (TypeScript)** — по умолчанию уже вставлен:

```ts
export function bubbleSort(source: number[]): number[] {
  const arr = [...source];
  const n = arr.length;
  for (let i = 0; i < n - 1; i += 1) {
    for (let j = 0; j < n - 1 - i; j += 1) {
      if (arr[j] > arr[j + 1]) {
        const tmp = arr[j];
        arr[j] = arr[j + 1];
        arr[j + 1] = tmp;
      }
    }
  }
  return arr;
}
```

Установите «Подпись листинга» = `Листинг 1 — Сортировка пузырьком`, нажмите «Скачать .docx (листинг)» — получите корректный Word-документ.
